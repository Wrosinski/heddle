# Security Policy

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Include the
affected version or commit, impact, reproduction steps, and any suggested
mitigation. Avoid public disclosure until the maintainer has assessed the report.

Private vulnerability reporting is not a support channel. This project provides
no support, response-time guarantee, remediation guarantee, or warranty. Do not
send credentials, production data, or unrelated personal information.

For ordinary defects and feature requests, use the public issue tracker at
https://github.com/Wrosinski/heddle/issues.
