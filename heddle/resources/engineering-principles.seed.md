# Engineering Principles

Author this document for the repository you are adopting. Replace the prompts
below with the host team's real preferences, then mark the frontmatter as
ratified only after a human has reviewed and accepted them.

## Inviolables

- Which constraints must every change preserve?

## Principles, ranked

1. Which principle wins when reasonable choices conflict?

## Defaults

- Which reversible defaults should contributors follow?

## Architecture

- Which owner decides each policy, state fact and write effect?
- Which direction may dependencies cross the repository's boundaries?
- Which interfaces must be public, and which details remain private?
- How do extensions use data and an existing resolver rather than parallel paths?
- Where does each responsibility live, and where are components assembled?

Resolve these questions for the host's actual consumers. They are authoring
prompts, not automatically ratified rules or a copied upstream policy.

## Editing

Record material amendments deliberately and ratify them with the responsible
human owner.
